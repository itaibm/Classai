# Lesson 27 — Mixed problems: money, measure and time
**Maths · Year 2 · Unit 8 (Year-end consolidation)** · 24 min · **Delivery: 🤖 fully AI** · **Kind: review**
**Objective:** "By the end, I can solve everyday problems with money, measurement and time."

## Flow (all AI, "pretend trip out" frame — shop → bus → measure)

- **Hook (0–3):** "A whole pretend trip out — can you handle the money AND the clock like a grown-up?" Retrieval: change is found by counting UP.
- **Explain (3–8):** the tutor models the whole trip once — total 30p + 25p = 55p, change from £1 by counting up on a whiteboard number line (55→60→100 = 45p), clock set to quarter past 3 (minute hand on the 3), ribbon measured from ZERO. Rule: match the tool to the job, read it carefully.
- **Example (8–13):** child runs the shop stop — totals 55p, leads the count-up to 45p change.
- **Check (13–17):** full money problem (total AND change from £1) with the count-up voiced. Traps handled: 65p total (ten-crossing slip), change 55p (guessed/mixed with total).
- **Practice (17–21):** 12 scenario cards rotating contexts, resurfacing the year's traps — coin VALUE vs coin count (three 2ps vs one 10p), ruler starting at 2 not 0 (→ 6 cm not 8 cm), "twenty to 4" ≠ 4:20 (→ 3:40), jug scale in 100s, £1 = 100p; stretch: two-step change (35p + 40p from £1 → 25p), minutes-until-the-bus, ribbons joined end to end vs compared.
- **Recap (21–24):** child names their strongest and shakiest context (logged for the Lesson 28 circuit). Process praise: "you switched tools for every job and read each one carefully."

**Adaptivity:** start level 2 · 2 right → up (combo cards at 3) · 2 misses → tool-on-screen reteach + level 1 · mastery = 4+ correct across all three contexts incl. a voiced count-up and a past/to time.

**No video** — consolidation lesson; the minutes go to scenario cards.

**Differentiation:** support — tools stay on screen, one context per card · stretch — two-context combo cards, digital times without the clock picture.
**Evidence:** totals + change by counting up, past/to times read and set, lengths measured from 0 — across interleaved contexts.
