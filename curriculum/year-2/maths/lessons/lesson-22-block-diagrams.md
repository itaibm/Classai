# Lesson 22 — Block diagrams: most, least, how many more
**Maths · Year 2 · Unit 7 (Statistics, shape and symmetry)** · 22 min · **Delivery: 🤖 fully AI**
**Objective:** "By the end, I can read a block diagram to answer 'most', 'least' and 'how many more'."
*(Human view of [`lesson-22-block-diagrams.json`](./lesson-22-block-diagrams.json) — the JSON is the source of truth. No preparation needed from you.)*

## Flow (all AI, animated car-colour chart built block by block on the whiteboard)

- **Hook (0–3):** "Which colour car passes the window most? Chart it and KNOW." Retrieval: 6 vs 4 → 2 more (difference).
- **Explain (3–8):** whiteboard stacks the chart one block at a time (red 6, blue 4, green 5, white 2). Rules land: **tallest = most, shortest = least**, "how many more" = **subtract** (6 − 4 = 2), "altogether" = add.
- **Example (8–13):** child reads the same chart — most, least, then dictates 5 − 2 = 3 for green vs white. Trap handled: "7" (added) → count only the blocks that stick out.
- **Check (13–17):** fresh pets chart, dogs 6 / cats 4 → **2 more dogs**. Wrong-answer playbook: "10" (added — 'more' read as 'altogether'), "6" (gave the bar height).
- **Practice (17–20):** adaptive 10-item bank — most/least and bar-top reading (level 1), 'how many more' by subtraction, totals, emoji-bar charts (level 2), stretch: question-word→operation matching, two-step (gap AND total), build a bar from a tally, add-on-'more' true/false (level 3).
- **Recap (20–22):** child states both rules; process praise for reading bar tops and picking the right sum.

**Adaptivity:** start level 2 · 2 right → up · 2 misses on a skill → scripted re-teach with bars side by side (count the sticking-out blocks) + level 1 · mastery = 3+ correct incl. one subtract-'more' and one add-'altogether'.

**Video:** none — the block-by-block whiteboard build carries it (per the KB honesty rule, no unverified link).

**Differentiation:** support — finger on each bar top, bars ≤ 6 · stretch — build a chart from a tally, two-step questions.
**Evidence:** reads most/least from heights; finds 'how many more' by subtracting (not adding); totals two bars.
