# Lesson 24 — Write your own instructions
**English · Year 2 · Unit 5 (Comprehension & composition)** · 30 min · **Delivery: 🤖 fully AI**
**Objective:** "By the end, I can write a clear set of instructions with commands and order words."
*(Human view of [`lesson-24-write-your-own-instructions.json`](./lesson-24-write-your-own-instructions.json) — the JSON is the source of truth. No preparation needed from you.)*

## Flow (all AI, "you're the author" frame — composition lesson, writing time protected)

- **Hook (0–3):** the child picks a real topic they know (game, snack, craft), sized to 3–4 steps. Retrieval: the three must-have features.
- **Explain (3–9):** full author model on "How to make toast" — plan first (title, you will need), then the **author's secret**: SAY each step aloud before writing it. Four steps, each order word + bossy verb (*put, press, wait, spread*).
- **Example (9–12):** plan THEIRS together — title, 'you will need' (shortText), and step one rehearsed aloud as a command (speak block). Check: why start with a bossy verb? → so the reader knows exactly what to do.
- **Check (12–14):** fast pre-flight gate — command step vs story sentence ("Then I cut along the line and it was fun") — then release to write.
- **Practice (14–26):** **the big write** (12 protected minutes): on-screen frame, say-it-then-write-it per step, whole text read back at the end. Wrong-answer playbook covers story-mode drafts and vague steps ("do the paper bit").
- **Recap (26–30):** author's reading aloud; tutor mimes following it exactly; process praise for the rehearse-aloud habit.

**Misconceptions targeted:** instructions written as a story/recount (no commands, no order words); diving in without a plan; vague unfollowable steps; missing 'you will need'.

**Practice bank:** 9 items — L1 order-word fillBlank, pick the real step (2) · L2 plan the top (title + list), write a command step, fix a muddled squash order, oral-rehearsal speak item (4) · L3 write the complete text, surgery on a recount ("I got a cup and then I…"), the **robot test** (spot the unaddressed envelope) (3). Every item: wrong answers diagnosed, hints, scripted reteach.

**Adaptivity:** start level 2 · 2 right → up · 2 misses → reteach + oral rehearsal before more writing · mastery = a complete, followable text read back aloud.

**Video:** none — the child's own writing carries the lesson (Unit 5's verified clip lives in Lesson 23).

**Differentiation:** support — frame with starters, 3-step topic, tutor scribes the list · stretch — robot-test your own text and fix the gap; add a Top tip.
**Evidence:** a finished instruction text — title, you-will-need, 3–4 numbered command steps with order words — read back aloud.
