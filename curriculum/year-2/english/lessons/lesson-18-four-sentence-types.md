# Lesson 18 — The four sentence types
**English · Year 2 · Unit 4 (Word classes & sentence types)** · 20 min · **Delivery: 🤖 fully AI**
**Objective:** "By the end, I can name the four sentence types and add the correct end mark."
*(Human view of [`lesson-18-four-sentence-types.json`](./lesson-18-four-sentence-types.json) — the JSON is the source of truth. No preparation needed from you.)*

## Flow (all AI, "four flavours" frame with voices)

- **Hook (0–3):** sentences come in four flavours — telling, asking, bossing, bursting — each read in its own voice. Speak block: child says *Where are you?* with the rising asking voice. Retrieval: capital + end mark.
- **Explain (3–8):** the anchor table — statement tells (.), question asks (?), command bosses (bossy verb first), exclamation bursts and **starts What/How** (!). Models sorting *Stop! / Where are you? / I am tired.*
- **Example (8–12):** shared categorize of four cards using the tool question "tell, ask, boss or burst?" — incl. the *How fast it runs!* trap (How ≠ asking here).
- **Check (12–14):** *Close the window.* → command, spotted by the bossy verb. Traps handled: "statement" (telling vs bossing), "exclamation" (mark ≠ type).
- **Practice (14–18):** adaptive 9-item bank — type ID + end-mark fills (level 1); four-way sorts, bossy-verb ID, speak-in-the-right-voice, *What a mess___* (level 2); stretch: **Stop! is a command not an exclamation** (mark vs type), a sort with a command wearing !, and write-all-four-types (level 3).
- **Recap (18–20):** child names the four types + marks; process praise ("you checked the first word's job instead of trusting the mark").

**Adaptivity:** start level 2 · 2 right → up · 2 misses on a skill → scripted re-teach with the four anchors + level 1 · mastery = 3+ correct incl. a bossy-verb command and a command-with-! not mislabelled.
