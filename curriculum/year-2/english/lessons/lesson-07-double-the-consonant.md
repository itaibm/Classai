# Lesson 7 — Double the consonant (run → running)
**English · Year 2 · Unit 2 (Spelling with suffixes)** · 20 min · **Delivery: 🤖 fully AI**
**Objective:** "By the end, I can double the final consonant of a short-vowel word before a vowel suffix."
*(Human view of [`lesson-07-double-the-consonant.json`](./lesson-07-double-the-consonant.json) — the JSON is the source of truth. No preparation needed from you.)*

## Flow (all AI, "twin letters protect the short sound" frame)

- **Hook (0–3):** *hoping* vs *hopping* — one letter apart, totally different meanings. The double letter is a superhero protecting the short sound. Retrieval: the short /o/ in *hop*.
- **Explain (3–8):** the test on the whiteboard: **one short vowel + one consonant on the end → double it** — run → running (else it reads "roo-ning"), hop → hopping; contrast hope → hoping (drop-e, Lesson 6).
- **Example (8–12):** shared deciding — bigger, sitting, swimming — child runs the test out loud; then reads *hoping/hopping* aloud so the difference is HEARD (speak block).
- **Check (12–14):** hop + -ing → **hopping**. Wrong-answer playbook: *hoping* (didn't double — now it means wishing), *hopeing* (drop-e mix-up).
- **Practice (14–18):** adaptive 9-item bank — running/sitting/true-false hop (level 1), swimming/hopped/bigger (level 2), stretch: choose *hoping vs hopping* in a sentence, *swimmer*, and "a friend wrote *runing* — what goes wrong?" (level 3).
- **Recap (18–20):** child states the test + why; optional verified video victory lap.

**Adaptivity:** start level 2 · 2 right → up · 2 misses on a skill → scripted re-teach tapping the one-vowel-one-consonant pattern + level 1 · mastery = 3+ correct across levels 2–3 incl. an -ed form and the hoping/hopping contrast.

**Misconceptions covered:** *runing* (didn't double — vowel goes long) · *hopeing* (wrong rule: drop-e) · doubling the wrong letter.

**Video (reinforce, ✅ verified 2026-07-03):** [Doubling the Final Consonant | Spelling Rules — EasyTeaching](https://www.youtube.com/watch?v=EmO1KoPY5aU). Task: shout the twin letters before the video shows them; after-check: when do we double?

**Differentiation:** support — rule card always on screen, -ing only first · stretch — explain hoping/hopping + spell biggest, swimmer.
**Evidence:** doubles correctly in 3+ CVC words (running, hopping, sitting) and contrasts hoping/hopping.
