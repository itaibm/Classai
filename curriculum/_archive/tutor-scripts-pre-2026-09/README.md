# Archived tutor scripts (pre-2026-09 outlines)

These word-for-word tutor scripts were written against the **old** lesson outlines, before the
curriculum was re-anchored to the charter's ages and each year was re-planned to the full brief
(see [`../../PLANNING-BRIEF.md`](../../PLANNING-BRIEF.md)). Their lesson numbers and titles no
longer match the current scope files, so they are kept here only as source material:

- `year-1/*/scripts/` — originally written for the old UK-style Year 2 (ages 6–7). The hand-built
  Year 1 lessons in `curriculum/year-1/*/lessons/` were derived from them and have been renumbered
  to the new sequence (`curriculum/year-1/ID-MAP.json`).
- `year-3/*/scripts/` — originally written for the old UK-style Year 4 (ages 8–9) outlines.

The app does not read these files. New scripts should be written against the current
`curriculum/year-N/<subject>/<subject>-year-N.md` numbering.
