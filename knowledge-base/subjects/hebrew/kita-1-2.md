# עברית — כיתות א'–ב' (גילאי 6–8): הקניית הקריאה והכתיבה

הקובץ הזה מכסה את שנת הקריאה (כיתה א') וביסוסה (כיתה ב'): מודעות פונולוגית, הא"ב, התנועות (ניקוד), הרכבת הברות, קריאה ראשונית, אותיות סופיות, כתב יד וכתיבה ראשונה. הנושאים מסודרים לפי סדר ההוראה. כל נושא ממלא את ארבעת שדות הניתוח.

---

## 1. מודעות פונולוגית — לשמוע את צלילי המילה

**Year / Key Stage:** כיתה א' (גילאי 6) · **Est. minutes:** 20 · **Subject strand:** קריאה — מוכנות

**Prerequisites:** none.

### Key concepts — מושגי מפתח
- למילה מדוברת יש **צלילים** שאפשר לשמוע ולשחק בהם — בלי קשר למשמעות.
- אפשר **לפרק** מילה לצלילים ו**לחבר** צלילים למילה.
- מזהים **צליל פותח** (במה מתחילה המילה) וצליל מסיים.

### Prior knowledge assumed — ידע קודם
- הילד מדבר עברית ומבין מילים יומיומיות.
- הילד יודע לחזור על מילה שאומרים לו.

### Teach it — איך מלמדים (ההסבר)
"בואו נשחק עם הָאוזניים, בלי אותיות בכלל. כשאני אומר 'שֶׁמֶשׁ' לאט-לאט — שמעתם? שְׁ... מֶ... שְׁ. שלושה צלילים! בואו נספור על האצבעות." מתחילים מהקל (חריזה, הברות) לקשה (צלילים בודדים): חריזה ("גַּם–שָׁם"), פירוק להברות במחיאות (שׁוֹ-קוֹ-לָד = שלוש), זיהוי צליל פותח, ואז פירוק לצלילים בודדים. הכול בעל־פה.

**Worked example.** מילה: "פִּיל". המורה: "באיזה צליל מתחילה 'פיל'? פְּ. ובאיזה נגמרת? לְ. ובאמצע? אִי. אז: פְּ–אִי–לְ — פיל!" הילד חוזר ומחבר.

### Hooks — וו עניין / חיבור לעולם
- משחק "אני רואה ב־": "אני רואה משהו שמתחיל ב־בְּ..." (בקבוק).
- שמות החברים: כמה הברות יש ב"דָּנִיֵּאל"? ננחית מחיאה לכל הברה.
- חיות: "פָּרָה" — באיזה צליל מתחילה? במה נגמרת?

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **אומר את שם האות במקום הצליל** ("פיל מתחיל בפֵּא").
  **Why:** מערבב בין שם האות לצליל שלה.
  **Fix:** "אנחנו לא אומרים את השם של האות, רק את הצליל: פְּ". מדגישים שזה משחק של אוזניים, עוד לא של אותיות.
- **שומע רק את ההברה ולא את הצליל הבודד** ("שמש = שַׁ-מֶשׁ", שני חלקים).
  **Why:** הברות נשמעות בקלות, צלילים בודדים — קשה.
  **Fix:** "רובוט" מדבר לאט מאוד ומותח כל צליל; אצבע אחת לכל צליל.

### Checks — בדיקות הבנה
- **Q:** במה מתחילה המילה "דֶּלֶת"? **A:** בצליל דְּ.
- **Q:** אֵילו צלילים יש ב"סוּס"? **A:** ס–וּ–ס (שלושה).
- **Q:** מצא מילה שמתחרזת עם "כַּדּוּר". **A:** למשל "צִנּוֹר" / "אַדוּר" (כל מילה שנגמרת ב־וּר).

### Activity / practice — פעילות ותרגול
משחק speak: המורה אומר 5 מילים, הילד מוחא לכל הברה וסופר; אחר כך אומר את הצליל הפותח של כל מילה. (multipleChoice: "באיזה צליל מתחילה 'תַּפּוּחַ'?" → תְּ / פְּ / חְ.)

### Resources — משאבים
- **כאן חינוכית — שירי הברות וחריזה לגיל הרך** (שירים שמחדדים צליל וחרוז).

## 2. סדר האותיות והכרת צורתן

**Year / Key Stage:** כיתה א' (גילאי 6) · **Est. minutes:** 20 · **Subject strand:** קריאה — הקניית אותיות

**Prerequisites:** מודעות פונולוגית — לשמוע את צלילי המילה.

### Key concepts — מושגי מפתח
- לכל אות **צורה**, **שם** ו**צליל** — ואת הצליל אנחנו צריכים לקריאה.
- בעברית קוראים וכותבים **מימין לשמאל**.
- לומדים את האותיות **אחת-אחת בסדר קבוע**, ומיד מתרגלים אותן.

### Prior knowledge assumed — ידע קודם
- הילד יודע לשמוע צליל פותח של מילה (מודעות פונולוגית).
- הילד מזהה את שמו הכתוב.

### Teach it — איך מלמדים (ההסבר)
מלמדים אות חדשה כל פעם, ומקשרים בין **צורה → צליל → מילה שמתחילה בה**. סדר נפוץ בספרי הלימוד מתחיל באותיות תכופות וקלות לכתיבה (למשל א, מ, ש, ל, ב, ת...) ולא בהכרח לפי הסדר האלפביתי המלא. לכל אות: מסתכלים על הצורה ("ל' היא הכי גבוהה"), אומרים את הצליל, מוצאים מילים שמתחילות בו, ומאמנים את היד לכתוב. חשוב: בשלב הזה האות לבדה עוד לא "מילה" — היא תקבל צליל מלא רק כשנוסיף לה תנועה (ניקוד).

**Worked example.** אות "מ": הצורה — שתי "גבעות". הצליל — מְ. מילים: מַיִם, מֶלֶךְ, מָה. הילד מצביע על כל מ' בדף ואומר "מ".

### Hooks — וו עניין / חיבור לעולם
- "אות של היום" — מחפשים אותה על שלטים, אריזות, שמות.
- שם הילד: "באיזו אות מתחיל השם שלך?"
- אותיות מהגוף/חומרים: מעצבים את האות מפלסטלינה או מהגוף.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **מבלבל אותיות דומות בצורה** (ב/כ, ד/ר, ה/ח/ת, ו/ז/ן).
  **Why:** ההבדל הוא בפרט קטן (פינה, "רגל", זנב).
  **Fix:** מסמנים את **הפרט המבחין** בצבע ("לב' יש בליטה למטה, לכ' אין"); משווים בזוגות.
- **קורא משמאל לימין** (כמו במספרים/אנגלית).
  **Why:** הרגל מסביבה דוברת מספרים/אנגלית.
  **Fix:** חץ אדום בתחילת השורה מימין; "מתחילים מהצד של היד שמחזיקה את הדלת".

### Checks — בדיקות הבנה
- **Q:** איזה צליל עושה האות ש? **A:** שְׁ.
- **Q:** הראֵה לי את האות ב' במילה "בַּיִת". **A:** האות הראשונה (מימין).
- **Q:** במה שונה ד' מ־ר'? **A:** לד' יש פינה/"עקב" בולט למעלה־ימין; ר' מעוגלת.

### Activity / practice — פעילות ותרגול
matchPairs: התאמת אות לצליל (מ↔מְ, ש↔שְׁ, ל↔לְ). categorize: מיון מילים לפי האות הפותחת.

### Resources — משאבים
- **כאן חינוכית — "אותיות ושירים" / שירי אותיות** (שיר לכל אות, צורה+צליל).
- **משרד החינוך, המרחב הפדגוגי — הוראת השפה העברית בכיתה א'** (חומרי הקניית אותיות).

## 3. התנועות והניקוד — חמש התנועות בעברית

**Year / Key Stage:** כיתה א' (גילאי 6) · **Est. minutes:** 22 · **Subject strand:** קריאה — ניקוד

**Prerequisites:** סדר האותיות והכרת צורתן.

### Key concepts — מושגי מפתח
- בעברית **התנועה לא נכתבת באות נפרדת אלא בניקוד** (נקודות וקווים מתחת/מעל/בתוך האות).
- יש חמש תנועות בסיסיות: **a, e, i, o, u**.
- כמה סימני ניקוד שונים נותנים אותו צליל (קמץ ופתח שניהם a; צירה וסגול שניהם e).

### Prior knowledge assumed — ידע קודם
- הילד מכיר את צליל העיצור של כמה אותיות.
- הילד שומע את התנועות בדיבור (מודעות פונולוגית).

### Teach it — איך מלמדים (ההסבר)
"לאות לבדה אין עדיין צליל שלם — היא צריכה **תנועה**. התנועה היא הקול הפתוח: a, e, i, o, u. בעברית לא כותבים אותן באות אלא בסימן קטן ליד האות." מציגים את חמש התנועות עם סימן ייצוגי וצליל: **פתח/קמץ ( ַ ָ ) = a**, **צירה/סגול ( ֵ ֶ ) = e**, **חיריק ( ִ ) = i**, **חולם ( ֹ או וֹ ) = o**, **שורוק/קובוץ ( וּ / ֻ ) = u**. בשלב הזה לא חייבים את כל השמות — חשוב הצליל.

**Worked example.** האות בּ עם תנועות שונות: בַּ (a) → "בַּ", בִּ (i) → "בִּי", בּוֹ (o) → "בּוֹ", בּוּ (u) → "בּוּ". אותה אות, צליל אחר — בגלל הניקוד.

### Hooks — וו עניין / חיבור לעולם
- "מכונת התנועות": מסובבים גלגל ניקוד מתחת לאות ושומעים איך הצליל משתנה.
- שמות: התנועה ב"דָּנָה" (a-a) לעומת "מִיכַל" (i-a).
- שירה: מאריכים את התנועה בשיר — "אַאַאַ", "אוּאוּאוּ".

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **מתעלם מהניקוד וקורא רק את העיצור** ("בּ" במקום "בַּ").
  **Why:** הניקוד נראה "קטן" ולא חשוב.
  **Fix:** "בלי תנועה אי-אפשר לפתוח את הפה — האות תקועה". מצביעים: קודם האות, אחר כך הניקוד, ואז הצליל המחובר.
- **חושב שלכל צליל תנועה יש רק סימן אחד**.
  **Why:** לא יודע שקמץ=פתח, צירה=סגול בצליל.
  **Fix:** "שני סימנים, אותו קול": משווים בַּ ו-בָּ — שניהם "בַּ".

### Checks — בדיקות הבנה
- **Q:** איזו תנועה עושה האות עם חיריק (נקודה מתחת)? **A:** i.
- **Q:** קרא: דּוֹ. **A:** "דּוֹ" (d + o).
- **Q:** איזה צליל ב־ ַ ואיזה ב־ ָ ? **A:** שניהם a.

### Activity / practice — פעילות ותרגול
multipleChoice: "מה הצליל של מ + חיריק?" → מָ / מִ / מוּ. speak: הילד קורא בקול שורת הברות עם תנועות מתחלפות.

### Resources — משאבים
- **משרד החינוך — מבדק קריאה וכתיבה לכיתה א', מדריך למורה** (סדר הוראת ניקוד והערכה).

## 4. הרכבת הברות — מצרפים עיצור ותנועה

**Year / Key Stage:** כיתה א' (גילאי 6–7) · **Est. minutes:** 22 · **Subject strand:** קריאה — פענוח

**Prerequisites:** התנועות והניקוד; סדר האותיות.

### Key concepts — מושגי מפתח
- **הברה** = עיצור + תנועה (בַּ, מִי, שׁוֹ).
- מצרפים שתי הברות → מילה (בַּ + יִת → בַּיִת).
- קוראים **משמאל-לימין בתוך השורה? לא — מימין לשמאל**, הברה אחר הברה.

### Prior knowledge assumed — ידע קודם
- הילד יודע את צליל העיצור של כמה אותיות.
- הילד מזהה את חמש התנועות בניקוד.

### Teach it — איך מלמדים (ההסבר)
זהו לב הקריאה הסינתטית: "ניקח אות, נדביק לה תנועה, ונקבל הברה — קול שלם". בּ + ַ = בַּ. אחר כך מחברים הברות: דָּ + ג = דָּג. עובדים לאט, "מותחים" את החיבור (בָּ...בַ...בָ) עד שהילד שומע מילה. תרגול הדרגתי: הברה בודדת → מילה בת שתי הברות → מילה קצרה במשפט. בשלב זה **כל המילים מנוקדות**.

**Worked example.** "סַל": ס + ַ = סַ, ועוד ל = "סַל". המורה מצביע על כל סימן בזמן הקריאה, ואז הילד קורא בקצב טבעי.

### Hooks — וו עניין / חיבור לעולם
- "מכונת מילים": גוררים אות + ניקוד יחד ושומעים הברה.
- מילים מהבית: "דַּלְת? לא — דֶּלֶת". מפרקים ומרכיבים מחדש.
- אוכל: "בָּ-נָ-נָה" — כמה הברות?

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **קורא אות-אות בלי לחבר** ("ס... ל..." ולא "סל").
  **Why:** נתקע בפענוח ולא ממזג לכדי מילה.
  **Fix:** "מתיחה" — אומרים רצוף ולאט ומאיצים עד מילה; אצבע מחליקה משמאל לשמאל מתחת להברות.
- **הופך סדר הברות** ("לַס" במקום "סַל").
  **Why:** בלבול כיוון קריאה.
  **Fix:** חץ קריאה; מתחילים תמיד מההברה הימנית.

### Checks — בדיקות הבנה
- **Q:** קרא: מָ + לֵא → ? **A:** "מָלֵא".
- **Q:** קרא את המילה: גַּן. **A:** "גַּן".
- **Q:** כמה הברות ב"שֻׁלְחָן"? **A:** שתיים (שֻׁל-חָן).

### Activity / practice — פעילות ותרגול
ordering: סדר הברות לכדי מילה (בַּ / יִת → בַּיִת). speak: קריאת רשימת מילים מנוקדות בקול.

### Resources — משאבים
- **יסוד — *קוראים בכיף*, מדריך למורה** (שיטת הקניה הברתית; חינמי לעיון).

## 5. קריאת מילים ומשפטים מנוקדים

**Year / Key Stage:** כיתה א' (גילאי 7) · **Est. minutes:** 25 · **Subject strand:** קריאה — פענוח

**Prerequisites:** הרכבת הברות.

### Key concepts — מושגי מפתח
- מחברים הברות למילים, ומילים ל**משפט** שיש לו משמעות.
- **רֶווח** בין מילים מסמן איפה מילה נגמרת ומתחילה.
- קוראים כדי **להבין**, לא רק כדי להוציא צלילים.

### Prior knowledge assumed — ידע קודם
- הילד מרכיב הברות ומילים מנוקדות.
- הילד מכיר את רוב האותיות והתנועות.

### Teach it — איך מלמדים (ההסבר)
מהמילה הבודדת אל המשפט. קוראים יחד משפט קצר ומנוקד, מצביעים על כל מילה, ואז שואלים "על מה זה?" — מחברים פענוח להבנה כבר מהרגע הראשון. מתחילים במשפטים צפויים ("הַחָתוּל יָשֵׁן.") ומרחיבים. מעודדים קריאה **חוזרת** של אותו משפט כדי לבנות שטף.

**Worked example.** משפט: "דָּנִי אוֹכֵל תַּפּוּחַ." קוראים מילה-מילה, ואז שואלים: "מה דני עושה?" — אוכל. "מה הוא אוכל?" — תפוח.

### Hooks — וו עניין / חיבור לעולם
- כרטיסיות משפט על דברים בכיתה ("הַסֵּפֶר עַל הַשֻּׁלְחָן").
- בועות דיבור בקומיקס פשוט.
- "מה אני עושה עכשיו?" — כותבים יחד משפט קצר על הילד וקוראים.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **קורא נכון אבל לא מבין** ("קראתי, אבל על מה זה?").
  **Why:** כל המשאבים הלכו לפענוח.
  **Fix:** קריאה חוזרת לשטף, ואז שאלה אחת קצרה על המשמעות אחרי כל משפט.
- **"בולע" את הרֶווחים** ומחבר שתי מילים.
  **Why:** לא משתמש ברווח כסימן גבול.
  **Fix:** "אצבע קופצת" מעל כל רווח; מסמנים את הרווחים בקו.

### Checks — בדיקות הבנה
- **Q:** קרא והבן: "הַכֶּלֶב רָץ." מה הכלב עושה? **A:** רץ.
- **Q:** כמה מילים במשפט "אִמָּא בִּשְּׁלָה מָרָק"? **A:** שלוש.
- **Q:** קרא: "יֵשׁ לִי כַּדּוּר אָדֹם." מה הצבע? **A:** אדום.

### Activity / practice — פעילות ותרגול
fillBlank: "הַ___ נוֹבֵחַ" (כלב). multipleChoice על הבנת משפט קצר. speak: קריאת 3 משפטים בקול, פעמיים כל אחד (שטף).

### Resources — משאבים
- **פיג'מה (ספריית פיג'מה / PJ Library בעברית) — ספרים מנוקדים לקריאה ראשונה**.

## 6. אותיות סופיות — ך ם ן ף ץ

**Year / Key Stage:** כיתה א'–ב' (גילאי 7) · **Est. minutes:** 18 · **Subject strand:** קריאה וכתיבה — אותיות

**Prerequisites:** סדר האותיות; קריאת מילים מנוקדות.

### Key concepts — מושגי מפתח
- חמש אותיות מקבלות **צורה אחרת בסוף מילה**: כ→ך, מ→ם, נ→ן, פ→ף, צ→ץ.
- הצליל **לא משתנה** — רק הצורה.
- אות סופית מופיעה **רק בסוף מילה**, אף פעם לא באמצע.

### Prior knowledge assumed — ידע קודם
- הילד מכיר את הצורה הרגילה של כ, מ, נ, פ, צ.
- הילד קורא מילים קצרות מנוקדות.

### Teach it — איך מלמדים (ההסבר)
"חמש אותיות לובשות 'מעיל ארוך' כשהן בסוף מילה — הצליל אותו צליל, רק הזנב מתארך כלפי מטה." מציגים זוגות: מ/ם (מַיִם), נ/ן (גַּן), כ/ך (מֶלֶךְ), פ/ף (סוֹף), צ/ץ (עֵץ). מדגישים את הכלל: סופית = רק בסוף.

**Worked example.** "מַיִם": ה־מ' הראשונה רגילה (תחילת מילה), והאחרונה סופית — ם. אותו צליל מְ.

### Hooks — וו עניין / חיבור לעולם
- "מצא את הזנב": סורקים דף ומקיפים אותיות סופיות.
- שמות: "יוֹסֵף", "אֵיתָן" — איפה הסופית?
- חיות: "צְפַרְדֵּעַ"... ואיפה תהיה ץ סופית? ("עֵץ").

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **כותב/קורא אות סופית באמצע מילה** ("םים" במקום "מים").
  **Why:** לא הפנים שסופית = רק בסוף.
  **Fix:** כלל ברזל: "סופית גרה רק בקצה השמאלי של המילה"; משווים מַיִם.
- **חושב שהסופית היא אות/צליל חדש**.
  **Why:** הצורה השונה מטעה.
  **Fix:** "אותו קול, מעיל אחר": מ ו-ם שניהם מְ.

### Checks — בדיקות הבנה
- **Q:** מה הצורה הסופית של נ? **A:** ן.
- **Q:** איזו אות סופית במילה "אֶרֶץ"? **A:** ץ (צ' סופית).
- **Q:** האם "םתוק" נכון? **A:** לא — צריך "מתוק" (מ' רגילה בהתחלה).

### Activity / practice — פעילות ותרגול
matchPairs: אות רגילה↔סופית (כ↔ך, פ↔ף...). categorize: מילים — "יש בה אות סופית" / "אין".

### Resources — משאבים
- **משרד החינוך — מבדק קריאה וכתיבה לכיתה א'** (כולל אותיות סופיות).

## 7. אותיות דומות בצליל — לא לבלבל בשמיעה

**Year / Key Stage:** כיתה א'–ב' (גילאי 7) · **Est. minutes:** 18 · **Subject strand:** קריאה — דיוק / כתיב

**Prerequisites:** הכרת רוב האותיות; הרכבת הברות.

### Key concepts — מושגי מפתח
- בעברית כמה זוגות אותיות נשמעים **כמעט אותו דבר**: ב/ו, ת/ט, כ/ק, ח/כ, א/ע, ס/שׂ.
- כשהצליל זהה, צריך **לזכור איזו אות** מתאימה למילה (זה עניין של כתיב, לא של פענוח).
- שומעים — אבל **כותבים נכון** לפי המילה.

### Prior knowledge assumed — ידע קודם
- הילד מכיר את האותיות ואת צליליהן.
- הילד מתחיל לכתוב מילים.

### Teach it — איך מלמדים (ההסבר)
"יש אותיות שאם נעצום עיניים — נשמע אותן אותו דבר: אַבָּא / אַווָּא נשמע דומה, אבל רק אחת נכונה." מסבירים שלכל מילה יש **כתיב נכון** שצריך לזכור, ושאת זה לומדים מתוך קריאה ותרגול. נותנים עוגנים: "תֵּה כותבים בת'", "כּוֹס כותבים בכ'", ולומדים מילים נפוצות בעל-פה. מבחינים בין **קריאה** (שם אין בעיה — הצליל יוצא) ל**כתיבה** (שם צריך לבחור).

**Worked example.** המילה "עֵץ" נשמעת כמו "אֵץ", אבל נכתבת בע'. לומדים אותה כמילה שמתחילה בע'.

### Hooks — וו עניין / חיבור לעולם
- "תאומים מבלבלים": כרטיסי זוגות (ת/ט, כ/ק) ומשחקים מי-מי.
- מילים מהבית שכותבים נכון: "בַּקבוק" (ב'), "טֶלֶפוֹן" (ט').
- שמות חברים: "עֹמֶר" בע', "אֹרֶן" בא'.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **כותב את האות לפי הצליל בלבד** ("קוּמ" במקום "כּוּם"? / "אֵץ" במקום "עֵץ").
  **Why:** כשהצליל זהה אין רמז בשמיעה.
  **Fix:** ללמוד את המילה הנכונה כ"תמונה" ולזכור עוגן; לתרגל מילים נפוצות שוב ושוב.
- **חושב שזו טעות בקריאה**.
  **Why:** מערבב פענוח עם כתיב.
  **Fix:** "בקריאה אין בעיה — שתי האותיות נשמעות נכון. הבעיה רק כשאני כותב ובוחר אות".

### Checks — בדיקות הבנה
- **Q:** איזו אות במילה "עֵץ" — א' או ע'? **A:** ע'.
- **Q:** "תֵּה" — בת' או בט'? **A:** בת'.
- **Q:** למה קל לטעות בין כ' לק'? **A:** כי הן נשמעות כמעט אותו צליל.

### Activity / practice — פעילות ותרגול
multipleChoice: בחר את האות הנכונה למילה ("__ץ" → ע/א). categorize: מיין מילים ל"בת'" / "בט'".

### Resources — משאבים
- **משרד החינוך, המרחב הפדגוגי — חינוך לשוני יסודי, הוראת כתיב** (אותיות בעלות צליל דומה).

## 8. כתב יד — צורת האות, כיוון וישיבה על השורה

**Year / Key Stage:** כיתה א' (גילאי 6–7) · **Est. minutes:** 20 · **Subject strand:** כתיבה — מוטוריקה

**Prerequisites:** הכרת צורת האותיות.

### Key concepts — מושגי מפתח
- כל אות נכתבת ב**כיוון וסדר קווים** קבועים, **מימין לשמאל**.
- אותיות "יושבות על השורה"; חלקן יורדות מתחתיה (ק, ן, ך, ף, ץ).
- כתב ברור = אפשר לקרוא אותו.

### Prior knowledge assumed — ידע קודם
- הילד מזהה את צורת האותיות.
- הילד אוחז עיפרון.

### Teach it — איך מלמדים (ההסבר)
"כל אות מתחילה בנקודה מסוימת ונכתבת בכיוון מסוים — כמו ללכת בשביל." מדגימים נקודת התחלה וחץ לכל אות, מאמנים באוויר, על חול/לוח, ואז על שורה. מדברים על **גודל אחיד** ועל **רֶווח** בין מילים (אצבע). מציינים אותיות שיורדות מתחת לשורה.

**Worked example.** האות ק': מתחילים מהקו העליון, יורדים ב"רגל" ארוכה מתחת לשורה, ואז הקשת. הילד כותב שלוש ק' בגודל אחיד.

### Hooks — וו עניין / חיבור לעולם
- "מסלול מרוץ": עוקבים עם האצבע אחרי חץ האות.
- כותבים את השם הפרטי יפה לתלייה.
- חול/בצק: מעצבים את האות לפני שכותבים.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **כותב אות "הפוכה" או מכיוון לא נכון** (מתחיל מלמטה/משמאל).
  **Why:** אין נקודת התחלה קבועה.
  **Fix:** נקודה ירוקה להתחלה וחץ; מאמנים את אותו מסלול שוב ושוב.
- **אותיות "מרחפות" או בגדלים שונים**.
  **Why:** אין מודעות לשורה.
  **Fix:** שורה עם "רצפה ותקרה"; "כל אות עומדת על הרצפה".

### Checks — בדיקות הבנה
- **Q:** מאיזה צד מתחילים לכתוב מילה? **A:** מימין.
- **Q:** איזו אות יורדת מתחת לשורה: מ' או ק'? **A:** ק'.
- **Q:** מה עוזר לשמור רֶווח בין מילים? **A:** רֶווח של אצבע.

### Activity / practice — פעילות ותרגול
פעילות מוטורית (לא דיגיטלית במלואה): שרטוט אותיות לפי חץ. ordering: סדר את שלבי כתיבת האות. speak/דיווח: "כתבתי את השם שלי — נכון על השורה?"

### Resources — משאבים
- **אחיה ידע / חומרי אימון אותיות כתב לכיתות א'–ב'** (דפי אימון צורת אות, חינמיים).

## 9. כתיבה פונטית של מילים — לכתוב מה ששומעים

**Year / Key Stage:** כיתה א' (גילאי 7) · **Est. minutes:** 22 · **Subject strand:** כתיבה — איות ראשוני

**Prerequisites:** מודעות פונולוגית; הכרת האותיות; כתב יד.

### Key concepts — מושגי מפתח
- כדי לכתוב מילה: **מפרקים אותה לצלילים** ובוחרים אות לכל צליל.
- מסמנים את **כל העיצורים** ואת התנועות (בעזרת ניקוד / אימהות קריאה).
- בשלב הזה מותר כתיב לא מושלם — העיקר שכל הצלילים מיוצגים.

### Prior knowledge assumed — ידע קודם
- הילד מפרק מילה לצלילים בעל-פה.
- הילד מכיר את צורת האותיות ואת הצלילים.

### Teach it — איך מלמדים (ההסבר)
זהו ההפך מקריאה: בקריאה **מצרפים**, בכתיבה **מפרקים**. "אני רוצה לכתוב 'סוּס'. נשמע לאט: ס–וּ–ס. לכל צליל אות." בשלב ההתחלתי בכיתה א' מקבלים כתיבה פונטית (לפי השמיעה), כולל ייצוג התנועות באותיות א/ה/ו/י — וזה תקין התפתחותית. בהדרגה מדייקים את הכתיב הנכון.

**Worked example.** "דָּג": שומעים ד–ָ–ג. כותבים ד, מוסיפים קמץ, מוסיפים ג → "דָּג".

### Hooks — וו עניין / חיבור לעולם
- "מילון של עצמי": כותבים מילים אהובות (שמות חברים, אוכל).
- תוויות לחפצים בכיתה.
- "מכתב לסבתא" קצרצר במילים בודדות.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **משמיט את התנועה** ("דג" בלי קמץ / "נת" במקום "נֵט").
  **Why:** תנועות באמצע קשות לשמיעה.
  **Fix:** "רובוט" מותח את התנועה; אצבע אחת לכל צליל לפני הכתיבה.
- **כותב משמאל לימין / הופך סדר אותיות**.
  **Why:** כיוון.
  **Fix:** מתחילים מימין; אומרים את הצלילים בקול תוך כדי כתיבה.

### Checks — בדיקות הבנה
- **Q:** אֵילו צלילים צריך לכתוב במילה "פִּיל"? **A:** פ–אִי(חיריק)–ל.
- **Q:** כתוב את המילה "גַּן" (מנוקד). **A:** גַּן.
- **Q:** מה חסר ב"דג" אם רצינו "דָּג"? **A:** הניקוד (קמץ) של התנועה a.

### Activity / practice — פעילות ותרגול
speak→write: המורה אומר מילה, הילד מפרק לצלילים ואז כותב. fillBlank: השלם את האות החסרה ("סו__" → ס). multipleChoice: כמה צלילים ב"שֶׁמֶשׁ"?

### Resources — משאבים
- **משרד החינוך — מבדק קריאה וכתיבה לכיתה א'** (כתיבה פונטית-גרפית כיעד).

## 10. ביסוס שטף — לקרוא בדיוק, במהירות ובהנגנה

**Year / Key Stage:** כיתה ב' (גילאי 7–8) · **Est. minutes:** 22 · **Subject strand:** קריאה — שטף

**Prerequisites:** קריאת מילים ומשפטים מנוקדים.

### Key concepts — מושגי מפתח
- **שטף** = קריאה מדויקת, בקצב סביר, עם **הנגנה** (לעצור בנקודה, להרים בסימן שאלה).
- שטף משחרר "ראש" ל**הבנה**.
- בונים שטף ב**קריאה חוזרת** של אותו טקסט.

### Prior knowledge assumed — ידע קודם
- הילד מפענח מילים ומשפטים מנוקדים נכון.
- הילד מכיר נקודה וסימן שאלה.

### Teach it — איך מלמדים (ההסבר)
"כשקוראים את אותו סיפור כמה פעמים — בכל פעם זה קל ויפה יותר, כמו לנגן שיר שמכירים." המורה קורא משפט בהנגנה, הילד חוזר (קריאת הד), אחר כך קוראים יחד, ואז הילד לבד. עוצרים בנקודה, מרימים את הקול בשאלה. מציינים שזו לא תחרות מהירות — אלא קריאה **חלקה ונעימה**.

**Worked example.** "מָה שְׁלוֹמְךָ? אֲנִי בְּסֵדֶר!" — בשאלה הקול עולה, בקריאה הקול מתלהב. קוראים שלוש פעמים עד שזורם.

### Hooks — וו עניין / חיבור לעולם
- "קורא כמו שחקן": קוראים בקול של דמות.
- מד-שטף אישי: כמה משפטים קראתי חלק?
- קריאה לבן/בת משפחה צעירים יותר.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **חושב ששטף = מהר ככל האפשר** (קורא מהר ושוגה).
  **Why:** מבלבל מהירות עם שטף.
  **Fix:** "שטף זה חלק ונעים, לא מרוץ". דיוק קודם, אחר כך קצב.
- **קורא במונוטוניות, בלי לעצור בפיסוק**.
  **Why:** מתעלם מסימני הפיסוק.
  **Fix:** "נקודה = לנשום ולעצור; סימן שאלה = הקול עולה". מסמנים את הפיסוק בצבע.

### Checks — בדיקות הבנה
- **Q:** מה עושים כשמגיעים לנקודה? **A:** עוצרים קצר / נושמים.
- **Q:** מה קורה לקול בסימן שאלה? **A:** עולה.
- **Q:** למה כדאי לקרוא טקסט יותר מפעם אחת? **A:** כדי שיהיה חלק וקל יותר (שטף).

### Activity / practice — פעילות ותרגול
speak: קריאה חוזרת ×3 של פסקה קצרה, עם תשומת לב לפיסוק. multipleChoice על הנגנה: "איך נקרא משפט עם סימן קריאה?"

### Resources — משאבים
- **כאן חינוכית — תוכניות קריאה והקראת סיפורים** (מודל קריאה בהנגנה).

## 11. דהיית הניקוד — מטקסט מנוקד לטקסט עם פחות ניקוד

**Year / Key Stage:** כיתה ב' (גילאי 8) · **Est. minutes:** 20 · **Subject strand:** קריאה — מעבר

**Prerequisites:** ביסוס שטף; קריאת מילים מנוקדות.

### Key concepts — מושגי מפתח
- ככל שמשתפרים — **מורידים בהדרגה את הניקוד**.
- בלי ניקוד, **אימהות הקריאה** (א, ה, ו, י) וההֶקשר עוזרים לדעת את התנועה.
- מילים מוכרות נקראות "בתמונה" גם בלי ניקוד.

### Prior knowledge assumed — ידע קודם
- הילד קורא בשטף עם ניקוד.
- הילד מכיר מילים נפוצות.

### Teach it — איך מלמדים (ההסבר)
"הניקוד היה 'גלגלי עזר' לאופניים — עכשיו שאתם רוכבים יפה, אפשר להוריד אותם לאט." מתחילים בהורדת ניקוד ממילים מוכרות מאוד, ואז מטקסטים מנוקדים-חלקית. מסבירים שהאותיות **ו** ו**י** מסמנות לעיתים תנועה (שׁוֹמֵר → ה־ו מסמנת o; בּיִת → ה־י מסמנת i), ושההֶקשר מכריע ("ספר" — סֵפֶר או סָפַר? תלוי במשפט).

**Worked example.** "אמא" בלי ניקוד — אנחנו כבר יודעים שזה "אִמָּא". "שלום" — "שָׁלוֹם" (ה־ו מרמזת על o).

### Hooks — וו עניין / חיבור לעולם
- "אתגר בלי גלגלי עזר": קוראים שלט אמיתי בלי ניקוד.
- שמות חברים בלי ניקוד.
- ספר/כותרת אהובים — קוראים את הכותרת הלא-מנוקדת.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **"נתקע" כשאין ניקוד ומנסה לפענח אות-אות**.
  **Why:** הסתמכות יתר על הניקוד.
  **Fix:** "תסתכל על המילה כולה — אתה מכיר אותה?"; משתמשים בהקשר המשפט.
- **קורא תנועה שגויה במילה דו-משמעית** ("סָפַר" במקום "סֵפֶר").
  **Why:** בלי ניקוד יש כמה אפשרויות.
  **Fix:** "קרא את כל המשפט — מה הגיוני?"; ההקשר בוחר.

### Checks — בדיקות הבנה
- **Q:** קרא בלי ניקוד: "שלום". **A:** "שָׁלוֹם".
- **Q:** באיזה תנועה עוזרת ה־ו ב"דוד"? **A:** o (דּוֹד).
- **Q:** "ילד הלך לבית ___" — מה עוזר לדעת איך לקרוא מילה לא מנוקדת? **A:** ההקשר/המשפט.

### Activity / practice — פעילות ותרגול
multipleChoice: "כתוב לא מנוקד 'בית' — איך קוראים?" → בַּיִת/בֵּית (לפי הקשר). fillBlank עם בחירת תנועה לפי משפט.

### Resources — משאבים
- **משרד החינוך, המרחב הפדגוגי — רכישת הקריאה** (מדיניות דהיית הניקוד).

## 12. כתיבת משפט שלם ופיסוק בסיסי

**Year / Key Stage:** כיתה ב' (גילאי 8) · **Est. minutes:** 22 · **Subject strand:** כתיבה — חיבור

**Prerequisites:** כתיבה פונטית של מילים; קריאת משפטים.

### Key concepts — מושגי מפתח
- **משפט** מתחיל באות (בעברית אין אות גדולה) ונגמר ב**סימן פיסוק**: נקודה (.), סימן שאלה (?), סימן קריאה (!).
- במשפט יש לפחות "מי" ו"מה עושה" (נושא ופועל — בשפה פשוטה).
- כותבים את מה שרוצים **לומר**, במשפט שלם.

### Prior knowledge assumed — ידע קודם
- הילד כותב מילים בודדות.
- הילד קורא משפטים מנוקדים.

### Teach it — איך מלמדים (ההסבר)
"משפט הוא רעיון שלם: מישהו, ומה הוא עושה. בסוף שמים סימן — נקודה אם סיפרנו, סימן שאלה אם שאלנו, סימן קריאה אם התרגשנו." מנסחים בקול לפני שכותבים ("מה אני רוצה לומר?"), כותבים, ואז **קוראים שוב** לבדוק שזה הגיוני ושיש סימן בסוף.

**Worked example.** רוצים לספר על החתול. אומרים בקול: "הֶחָתוּל יָשַׁן עַל הַסַּפָּה." כותבים, ובסוף שמים נקודה. שואלים? "אֵיפֹה הֶחָתוּל?" — סימן שאלה.

### Hooks — וו עניין / חיבור לעולם
- "יומן של דקה": משפט אחד על משהו שקרה היום.
- כיתוב לתמונה/ציור שהילד צייר.
- חידות: כותבים שאלה (עם ?) וחבר עונה.

### Misconceptions — טעויות נפוצות (תשובה שגויה → למה → תיקון)
- **כותב רשימת מילים בלי משפט / בלי סימן בסוף**.
  **Why:** עוד לא תופס "משפט" כיחידה שלמה.
  **Fix:** "מי? + מה עושה? + סימן בסוף". קוראים בקול לבדוק שזה נשמע שלם.
- **שם סימן שאלה במשפט שמספר** (או להפך).
  **Why:** לא מקשר בין הסימן למטרת המשפט.
  **Fix:** "סיפרתי → נקודה; שאלתי → ?; התרגשתי → !".

### Checks — בדיקות הבנה
- **Q:** איזה סימן בסוף "אֵיךְ קוֹרְאִים לְךָ"? **A:** סימן שאלה (?).
- **Q:** האם "כֶּלֶב חָתוּל בַּיִת" הוא משפט? **A:** לא — זו רשימת מילים בלי "מה עושה".
- **Q:** השלם למשפט: "הַיֶּלֶד ___". **A:** למשל "רָץ." (פועל + נקודה).

### Activity / practice — פעילות ותרגול
fillBlank: השלמת פועל למשפט. multipleChoice: בחר את הסימן הנכון לסוף המשפט. speak→write: נסח בקול ואז כתוב משפט על היום שלך.

### Resources — משאבים
- **משרד החינוך, המרחב הפדגוגי — הוראת הכתיבה בכיתות א'–ב'** (משפט ופיסוק ראשוני).
