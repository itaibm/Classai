# Hebrew Literacy (קריאה וכתיבה) — Subject Overview, Grades 1–6

English index line: This is the self-contained **Hebrew first-language literacy** knowledge base for the Classai tutor (native readers, ages 5–12), anchored to the **Israeli Ministry of Education** *חינוך לשוני* (linguistic education) curriculum for the elementary school (כיתות א'–ו'). `subjectKey: language_arts`. All teaching content below is in Hebrew; section headings are bilingual so the app can parse the four analysis fields.

---

## על מה מבוסס בסיס הידע הזה — מקורות והכוונה

בסיס הידע נשען על מסמכי **משרד החינוך — אגף שפות, חינוך לשוני יסודי** (תכנית הלימודים "חינוך לשוני: עברית — שפה, ספרות ותרבות"), על מדריך **"מבדק קריאה וכתיבה לכיתה א'"** (ראמ"ה / האגף לחינוך יסודי), ועל ספרי הקריאה הנפוצים בישראל (יסוד — *קוראים בכיף*, מטח). הדגש הוא על מה שבאמת מלמדים בכיתה הישראלית: **הקניית הקריאה** בכיתה א', שטף, הבנת הנקרא, כתיב ודקדוק.

## איך מלמדים אוריינות בעברית — שיטות ההוראה (ה־playbook)

האוריינות בעברית נשענת על כמה עמודי תווך. גם כשנושא השיעור "על" אחד מהם — כדאי שהמורה יזכור את כולם.

### 1. מודעות פונולוגית — השער לקריאה
לפני שילד מצליח לקרוא הוא צריך לשמוע שלשפה יש **צלילים**. מודעות פונולוגית = היכולת לשחק בצלילי הדיבור בלי קשר למשמעות: לחרוז, לפרק מילה לצלילים (*שָׁמֶש* → ש-מ-ש), לחבר צלילים למילה, לזהות צליל פותח (במה מתחילה "דֶּלֶת"? בְּ־דְּ), להחליף או להשמיט צליל. זוהי המנבא הטוב ביותר להצלחה בקריאה, והיא נבנית בעל־פה, בלי אותיות, כבר בגן ובתחילת כיתה א'.

### 2. הקניית הקריאה — השיטה הפונמית־סינתטית (השיטה הנהוגה)
בישראל מלמדים קריאה בעיקר ב**שיטה הפונמית־סינתטית** (לעיתים בשילוב מאוזן): מלמדים את הקשר בין **אות + ניקוד → צליל**, ואז **מצרפים (מרכיבים) צליל אחר צליל למילה**. (השיטה ה"גלובלית" — זיהוי מילים שלמות "בתמונה" — נחשבת לא יעילה כשיטה עיקרית להקניה ראשונית, כי היא לא נותנת לילד כלי לפענח מילה חדשה.)
- **פונמה** = יחידת הצליל הקטנה ביותר (בְּ "שֶׁמֶשׁ" יש שלושה עיצורים ושני תנועות).
- **אות + ניקוד** = הסימן הכתוב. בעברית **התנועה מסומנת בניקוד** (נקודות וקווים), לא באות נפרדת — וזה שונה מאנגלית.
- **הרכבה (צירוף)** לקריאה: בּ + ַ (פתח) → "בַּ"; בַּ + יִת → "בַּיִת".
- **פירוק (ניתוח)** לכתיבה: שומעים "סוּס", מפרקים לצלילים ס-וּ-ס, וכותבים.
ההקניה היא **הדרגתית**: אות־אות (או צמד אותיות) בסדר קבוע, חזרה יומיומית, ויישום מיידי בקריאה ובכתיבה אמיתיות. אין לבקש מילד לקרוא מילה שיש בה אות שעוד לא נלמדה.

### 3. הניקוד — ומתי "מדהים" אותו
ילד ישראלי לומד לקרוא **עם ניקוד מלא** (טקסט מנוקד). הניקוד הוא "פיגום": הוא נותן את התנועה המדויקת ומאפשר פענוח. ככל שהקריאה משתפרת (סוף א' → ב'–ג') **מדהים (מדללים) את הניקוד** בהדרגה: עוברים לטקסטים מנוקדים חלקית ואז לטקסט לא מנוקד, שבו הילד נשען על זיהוי מילים, הקשר ו**אימהות הקריאה** (א, ה, ו, י). זהו מעבר מתוכנן, לא קפיצה.

### 4. שטף — הגשר בין פענוח להבנה
פענוח לבד איטי. **שטף** = לקרוא בדיוק, במהירות סבירה ועם הנגנה (אינטונציה). בלי שטף הילד משקיע את כל המשאבים בפענוח ולא נשאר לו "ראש" להבין. בונים שטף בקריאה חוזרת, קריאה בקול, קריאה בזוגות וקריאת טקסטים מוכרים.

### 5. הבנת הנקרא — זו המטרה
לפענח זה להוציא את המילים מהדף; **להבין** זה לדעת מה הן אומרות. מלמדים אסטרטגיות במפורש: **איתור** מידע גלוי, **הסקה** (מה שכתוב "בין השורות"), **ניבוי**, **הבהרת מילים לא מוכרות**, **סיכום** ו**שאילת שאלות** על הטקסט. הבנה נשענת על **ידע עולם ואוצר מילים** — ילד מסיק רק ממה שהוא כבר יודע.

### 6. כתיבה — יותר מאיות
כותבים טובים לא כותבים טיוטה מושלמת בבת אחת. מלמדים כתיבה כ**תהליך**: תכנון → כתיבה → שכתוב → הגהה. מפרידים בין **תוכן** (רעיונות, סדר, מילים) לבין **שיטחיות** (כתיב, פיסוק, צורת אות), כדי שהילד לא יקרוס תחת שניהם בבת אחת. מלמדים **סוגות** במפורש (סיפור, תיאור, הנחיות, מכתב, טיעון) — כל אחת והמבנה והמטרה שלה. תמיד נותנים **נמען ומטרה** אמיתיים.

### 7. דיבור והקשבה (תקשורת בעל־פה)
מי שיודע **לומר** רעיון יוכל גם לכתוב אותו. בכל הכיתות: נותנים לילד לנסח בקול לפני שכותב, מבקשים תשובות במשפט שלם, מרחיבים אוצר מילים בשיחה, ומלמדים להקשיב ולקחת תור.

## רצף ההוראה לפי כיתה (Scope & sequence, א'–ו')

### כיתה א' — שנת הקריאה
מודעות פונולוגית → הכרת **כל אותיות הא"ב** (בסדר קבוע, אות־אות) → **חמש התנועות** (קמץ/פתח = a, צירה/סגול = e, חיריק = i, חולם = o, שורוק/קובוץ = u) → **הרכבת הברות** (עיצור+תנועה) → קריאת מילים מנוקדות → קריאת משפטים וסיפורים קצרים מנוקדים. במקביל: **כתב יד** (צורת האותיות, כיוון, ישיבה על השורה) וכתיבה פונטית של מילים.

### כיתה ב' — ביסוס ושטף
שליטה בקריאה מנוקדת מדויקת ומהירה → תחילת **דהיית הניקוד** (טקסטים מנוקדים חלקית) → **אותיות סופיות** (ך ם ן ף ץ) ביסוס → **שווא, דגש, אותיות בכ"פ** (קריאה) → קריאת ספרים קצרים → כתיבה: משפטים שלמים, סיפור אישי קצר, פיסוק בסיסי (נקודה, סימן שאלה).

### כיתה ג' — מעבר ללא ניקוד והבנה
מעבר משמעותי ל**טקסט לא מנוקד** (אימהות הקריאה, כתיב מלא) → **שטף** מבוסס → אסטרטגיות **הבנת הנקרא**: איתור והסקה → **כתיב** נכון (כתיב מלא, ו/י אם וקמ"ץ) → **דקדוק**: שם עצם / פועל / שם תואר, זכר/נקבה, יחיד/רבים → כתיבת **פסקה** מאורגנת.

### כיתה ד' — הרחבה
הבנת הנקרא בטקסטים ארוכים יותר, מידעיים וספרותיים → **רעיון מרכזי וסיכום** → זמני הפועל (עבר/הווה/עתיד) → **שורש** (היכרות ראשונית) → אוצר מילים, מילים נרדפות והפכים → כתיבה לפי סוגה (סיפור, תיאור, הנחיות) עם מבנה פתיחה–גוף–סיום.

### כיתה ה' — העמקה
**הסקה ופרשנות** מורכבות, הבחנה בין עובדה לדעה → סוגות (סיפור, מאמר מידע, שיר) ומאפייניהן → **בניין** (היכרות בסיסית) ו**שורש ומשקל** ברמת ילד → כתיבה **מורחבת**: סיפור עם עלילה ודמויות, כתיבה תיאורית → אמצעים אמנותיים פשוטים (דימוי).

### כיתה ו' — לקראת חטיבה
הבנה ביקורתית, זיהוי עמדת הכותב, השוואה בין טקסטים → **כתיבת טיעון** (טענה–נימוק–דוגמה) ופסקה משכנעת → דקדוק: ביסוס מערכת הפועל (בניינים, גזרות בסיסי), שם הפועל, מילות יחס/חיבור → אוצר מילים עשיר, ביטויים וניבים → הגהה עצמית של כתיב ופיסוק.
