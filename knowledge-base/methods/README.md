# Teaching Methods Library — "all methods, all practices"

This is the heart of the knowledge base: a comprehensive, browsable catalogue of **teaching methods, strategies, routines and frameworks** for educating children ages 5–11, written so both a human teacher and the Classai AI tutor can choose the right method for the moment. It is curriculum-agnostic — these methods work whatever the subject or standard.

Every method follows the same entry format (see [`_METHOD-TEMPLATE.md`](_METHOD-TEMPLATE.md)): what it is, why it works, when to use / NOT, how to run it, the **1:1 AI-tutor adaptation** (how Classai applies it), a primary example, pitfalls, and related methods. Evidence strength is stated honestly, and fads/debunked ideas are flagged **AVOID**.

## How to choose a method (quick guide)

- **Teaching something new?** → explicit instruction + worked examples + CPA ([`instruction-models`](instruction-models.md), [`representation-and-modelling`](representation-and-modelling.md)). Save inquiry for *after* foundations.
- **Making it stick?** → retrieval practice + spacing ([`retrieval-and-memory`](retrieval-and-memory.md)).
- **Child stuck?** → scaffold & fade, diagnose the broken step ([`mastery-and-personalised`](mastery-and-personalised.md), [`assessment-methods`](assessment-methods.md)).
- **Child bored / anxious?** → SDT, interest hooks, appropriate challenge ([`motivation-and-engagement`](motivation-and-engagement.md)).
- **Checking understanding?** → hinge questions, good question stems, exit tickets ([`questioning-and-dialogue`](questioning-and-dialogue.md), [`assessment-methods`](assessment-methods.md)).
- **Different kind of learner?** → [`differentiation-and-inclusion`](differentiation-and-inclusion.md).

## The evidence behind these methods
The two research syntheses ground this library in the strongest evidence: [`../teaching/research-learning-science.md`](../teaching/research-learning-science.md) and [`../teaching/research-ai-tutoring.md`](../teaching/research-ai-tutoring.md). The [`../teaching/pedagogy-core.md`](../teaching/pedagogy-core.md) file is the condensed playbook; this folder is the full catalogue.

> Golden rule across every method: **keep the child doing the cognitive work.** A method that does the thinking *for* the learner — over-helping, passive watching, answer-giving — has failed, however engaging it looks.
